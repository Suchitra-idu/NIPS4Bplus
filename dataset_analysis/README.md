# dataset_analysis

Code behind `../DATASET_ANALYSIS.md`. Every number and figure in that report
is generated by these scripts from the raw data in `../raw/` — nothing in
the report is hand-computed or transcribed from the papers.

## Layout

```
scripts/
  common.py                      shared paths + a waveform-feature function
                                  used by both whole-file and per-event extraction
  extract_audio_features.py      1,687 wavs (687 train + 1000 test) -> data/audio_features.csv
  extract_annotation_data.py     674 temporal-annotation csvs -> data/events.csv,
                                  file_summary.csv, simultaneity.csv, cooccurrence_*.csv
  extract_event_audio_features.py  slices each of the 5,775 tagged events out of its
                                  source wav and computes the same feature set -> data/event_audio_features.csv
  statistical_analysis.py        descriptive stats, normality tests, distribution
                                  fitting, class-imbalance metrics, correlations,
                                  train/test shift -> various data/*.csv, *.json
  make_figures.py                every PDF in figures/

data/       generated CSV/JSON tables (git-ignored inputs, not the code itself)
figures/    generated PDFs referenced by DATASET_ANALYSIS.md
```

## Reproducing

Requires the packages this session installed into `.venv`:
`numpy scipy pandas soundfile matplotlib seaborn statsmodels librosa`.

```bash
cd dataset_analysis/scripts
python3 extract_audio_features.py        # ~1 min, reads all 1,687 wavs
python3 extract_annotation_data.py       # a few seconds
python3 extract_event_audio_features.py  # ~15s
python3 statistical_analysis.py          # a few seconds
python3 make_figures.py                  # ~10s
```

Each script is independent and re-runnable; they only read from `../../raw/`
and `data/`, and only write into `data/` or `figures/`. Nothing under
`dataset_analysis/` touches the SincNet training/eval pipeline.
